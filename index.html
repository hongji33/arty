✅ 준비물 체크리스트

수업별 준비물을 목록으로 만들고 체크하세요. 여러 개의 목록을 만들 수 있어요.

📅 주별 수업계획

학기 시작일과 주차 수를 정하면 주차별 날짜가 자동으로 나와요. 행사 주간은 '행사'로 표시하면 수업칸이 잠기고, 각 주마다 어느 반이 했는지 체크할 수 있어요. 인쇄(PDF 저장)도 됩니다.

🎲 랜덤 뽑기

발표자나 모둠을 랜덤으로 정해요. 이름을 넣거나 자리배치의 반 명단을 불러올 수 있어요.

🧹 정리 담당: 바닥 쓸기 · 책상 닦기 · 붓·팔레트 정리 · 작품 걷기 · 재료 정리 를 자동으로 나눠줘요.
여기에 결과가 나와요

🏆 모둠 점수판

모둠별로 점수를 올리고 내려요. '칠판에 크게 띄우기'로 학생들과 함께 보며 활동을 격려하세요. 점수는 자동 저장돼요.

🗂️ 학생 체크

반별 명단으로 작품 제출·수행평가·참여도를 한 번에 확인해요. 이름을 클릭하면 표시가 바뀌고, 자동으로 저장돼요.

📚 수업 편집기

학생 사이트 「수업 바로가기」에 보일 수업을 직접 만들고 고쳐요. 다 만든 뒤 lessons.json 내보내기로 파일을 받아 artclass 저장소에 올리면 모든 학생 화면에 반영돼요.

📌 사용 순서
  1. ① 불러오기로 현재 학생 사이트의 수업을 가져와요(처음 한 번).
  2. 학년을 고르고 ＋ 새 수업을 만들거나, 목록에서 수정을 눌러 고쳐요.
  3. ② lessons.json 내보내기로 파일을 받아요.
  4. 그 파일을 artclass 저장소(학생 사이트)에 올리면 끝!

🖼️ 화가 편집기

학생 사이트 「추천 화가·디자이너」에 보일 인물을 추가·수정해요. artists.json 내보내기로 파일을 받아 artclass 저장소에 올리면 학생 화면에 반영돼요.

📌 사용 순서: ① 불러오기 → 분류 고르고 ＋ 새 화가 / 수정 → ② artists.json 내보내기 → artclass 저장소에 올리기

⏱️ 미술실 타이머

미술 수업 단계별로 시간을 재요. 시작하면 단계가 자동으로 넘어가고, 소리로 알려줘요. '칠판에 크게 띄우기'로 학생들과 함께 보세요.
