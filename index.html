✅ 준비물 체크리스트

수업별 준비물을 목록으로 만들고 체크하세요. 여러 개의 목록을 만들 수 있어요.

📅 주별 수업계획

학기 시작일과 주차 수를 정하면 주차별 날짜가 자동으로 나와요. 행사 주간은 '행사'로 표시하면 수업칸이 잠기고, 각 주마다 어느 반이 했는지 체크할 수 있어요. 인쇄(PDF 저장)도 됩니다.

🎲 랜덤 뽑기

발표자나 모둠을 랜덤으로 정해요. 이름을 넣거나 자리배치의 반 명단을 불러올 수 있어요.

미술실 자리배치에서 체크한 오늘 결석자는 자동으로 제외됩니다.
🧹 정리 담당: 바닥 쓸기 · 책상 닦기 · 붓·팔레트 정리 · 작품 걷기 · 재료 정리 를 자동으로 나눠줘요.
여기에 결과가 나와요

🏆 모둠 점수판

모둠별로 점수를 올리고 내려요. '칠판에 크게 띄우기'로 학생들과 함께 보며 활동을 격려하세요. 점수는 자동 저장돼요.

🗂️ 학생 체크

반별 명단으로 작품 제출·수행평가·참여도를 한 번에 확인해요. 이름을 클릭하면 표시가 바뀌고, 자동으로 저장돼요.

📚 수업 편집기

「수업 바로가기」에 보일 수업을 직접 만들고 고쳐요. 수업 바로가기는 funart 사이트에만 있어요.

📌 사용 순서
  1. ① 불러오기로 현재 funart 사이트의 수업을 가져와요(처음 한 번).
  2. 학년을 고르고 ＋ 새 수업을 만들거나, 목록에서 수정을 눌러 고쳐요.
  3. ② lessons.json 내보내기로 파일을 받아요.
  4. 그 파일을 funart 저장소에 올리면 끝!

🤖 AI로 수업 초안 만들기

간단한 내용만 넣고 프롬프트 복사를 누른 뒤, 아무 AI(클로드·제미나이·챗지피티 등)에 붙여넣으면 이 페이지 형식에 맞는 수업이 만들어져요. 그 결과(JSON)를 아래 '②'에 붙여넣으면 수업 목록에 추가돼요.

📥 AI가 만든 수업(JSON) 붙여넣기

AI가 만들어 준 JSON을 여기에 붙여넣고 버튼을 누르면, 위에서 고른 학년의 수업 목록에 추가돼요. (```로 감싸져 있어도 괜찮아요.)

🖼️ 화가 편집기

「추천 화가·디자이너」에 보일 인물을 추가·수정해요. 이 메뉴는 artclass·funart 두 사이트 모두 관리할 수 있어요. 아래에서 대상 사이트를 고르세요.

📌 사용 순서: 대상 사이트 선택 → ① 불러오기 → 분류 고르고 ＋ 새 화가 / 수정 → ② artists.json 내보내기 → 해당 저장소에 올리기

⏱️ 미술실 타이머

미술 수업 단계별로 시간을 재요. 시작하면 단계가 자동으로 넘어가고, 소리로 알려줘요. '칠판에 크게 띄우기'로 학생들과 함께 보세요.

🎨 학생 사이트 주소

두 학생 사이트의 인터넷 주소예요. 편집기의 '불러오기·미리보기'와 사이드바 '학생 화면으로 가기'가 이 주소를 사용해요. (GitHub Pages 주소)

🚀 한 번에 발행 설정 (깃허브 토큰)

깃허브 토큰(열쇠)을 여기 한 번만 넣어두면, 편집기의 🚀 한 번에 발행 버튼으로 파일을 자동으로 올릴 수 있어요. 파일을 내려받아 다시 올릴 필요가 없어져요. 토큰은 이 브라우저에만 저장되고 공개되지 않아요. (무료예요)

토큰 만드는 법이 궁금하면 지연님(선생님)께 물어보거나 안내를 참고하세요. 권한은 funart·artclass 저장소의 Contents(내용) 쓰기만 있으면 돼요.

💾 전체 데이터 백업·복원

자리배치·재료·체크리스트·메모 등 모든 데이터를 파일 하나로 저장하거나, 다른 컴퓨터에서 불러올 수 있어요.
